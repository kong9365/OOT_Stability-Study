========================================================
 광동 품질·시험 통합 대시보드 — 빠른 시작 (3단계)
========================================================

[준비] 사내망(또는 VPN)에 연결돼 있어야 합니다.

1) Python 설치 (이미 있으면 건너뛰기)
   - https://www.python.org/downloads/ 에서 다운로드
   - 설치 첫 화면에서 "Add Python to PATH" 체크 후 Install

2) setup.bat 더블클릭   (처음 한 번만, 1~3분)
   - "[OK] Setup complete" 가 보이면 성공

3) run.bat 더블클릭      (실행)
   - 잠시 후 브라우저가 자동으로 열립니다 (http://localhost:8600)
   - 안 열리면 직접 주소 입력 또는 새로고침(F5)
   - 끄려면: 검은 창을 닫기
